# Restaurant Management System

## Features

### Admin
- Manage staff
- Add, edit, and delete staff
- View sales reports
- View customer feedback
- Update admin profile

### Manager
- Manage restaurant operations
- Manage menu and ingredients
- Manage orders

### Chef
- View and manage orders
- Manage food preparation

### Customer
- View menu
- Place orders
- Provide feedback

## Technologies Used

- Python
- File Handling
- Functions
- Modules
- Conditional Statements
- Loops
- Input Validation
